    Generate a save

    Choose a checkpoint from a recorded PC playthrough, then edit and download both files. These saves keep that playthrough’s choices and world state.

    Generated saves start with the name Chara. Based on Putnam3145’s 2015 PC playthrough. Savepoint checked the file structure and route data. Loading on current PC builds has not been tested.

    Use your own checkpoint files

    Choose a milestone or name your own. Add file0 and undertale.ini from the same save. You can keep a draft here while you test it in the game.

    Need a starting save? Browse the UNDERTALE community save packs. Check the author's version and route notes and choose only the two save files.

    PLAYER GUIDE

    Save folder & recovery

    1. Quit UNDERTALE completely.
    2. Copy your whole save folder to a safe place.
    3. Place the downloads in the folder as file0 and, if used, undertale.ini. If the game fails to load, quit and restore your backup folder.
    Windows
    %LOCALAPPDATA%\UNDERTALE
    macOS
    ~/Library/Application Support/com.tobyfox.undertale/
    Linux (Steam)
    ~/.config/UNDERTALE/

    file9 is used for autosaves and Game Over recovery. Leave it to the game.
